## 关于 im-uikit-uniapp

im-uikit-uniapp 是基于网易云信 IM SDK 的一款 uniapp UI 组件库，它提供了一些通用的 UI 组件，包含会话、聊天、群组等功能。基于 UI 组件您可以像搭积木一样快速搭建起自己的业务逻辑。im-uikit-uniapp 本身基于 `UIKitStore` 开发，API 参考 [UIKitStore](https://doc.yunxin.163.com/docs/interface/messaging/web/typedoc/UIKit/Latest/zh/modules.html)。

## 运行 demo

- [创建应用并获取 AppKey](https://doc.yunxin.163.com/console/docs/TIzMDE4NTA?platform=console)
- [注册云信账号，获取 account、token](https://doc.yunxin.163.com/messaging/docs/DQ3Nzk1MTY?platform=server)

### im-uniapp-ui

`im-uniapp-ui` 是 Vue3 版本 demo，运行方式如下：

1. 进入项目目录并安装依赖：

   ```bash
   cd im-uniapp-ui
   npm install
   ```

2. 在 `im-uniapp-ui/App.vue` 中填入 `appkey`、`account` 和 `token`。
3. 使用 HBuilderX 导入 `im-uniapp-ui` 目录。
4. 在 HBuilderX 中选择对应平台运行项目，例如运行到浏览器、微信小程序、Android 或 iOS。

### im-uniapp-ui-vue2

`im-uniapp-ui-vue2` 是 Vue2 版本 demo，运行方式如下：

1. 使用 HBuilderX 导入 `im-uniapp-ui-vue2` 目录。
2. 在 `im-uniapp-ui-vue2/App.vue` 中填入 `appkey`、`account` 和 `token`。
3. 在 HBuilderX 中选择对应平台运行项目，例如运行到浏览器、微信小程序、Android 或 iOS。
